## Step 6: give the current champion its own folder

Run in an authorized Cloud Shell. No repository clone, local model files, service-account keys, or Docker build is needed. If authentication fails, authorize Cloud Shell as the project owner before retrying.

```bash
(
set -e
gcloud config set project credit-risk-group3-513720
CREDIT_PROJECT=credit-risk-group3-513720
CREDIT_REGION=us-central1
CREDIT_BUCKET=credit-risk-models-group3-513720
CREDIT_URL=$(gcloud run services describe credit-risk-api --project="$CREDIT_PROJECT" --region="$CREDIT_REGION" --format='value(status.url)')
test -n "$CREDIT_URL"
curl --fail-with-body -sS --max-time 120 "$CREDIT_URL/model-info"
gcloud storage cat "gs://$CREDIT_BUCKET/model_info.json" | python3 -c 'import json,sys; x=json.load(sys.stdin); assert str(x["version"])=="1", "Stop: root bundle is not version 1"; print("Confirmed root bundle version 1")'
gcloud storage cp "gs://$CREDIT_BUCKET/model.joblib" "gs://$CREDIT_BUCKET/model_info.json" "gs://$CREDIT_BUCKET/feature_store.parquet" "gs://$CREDIT_BUCKET/models/v1/"
gcloud storage ls "gs://$CREDIT_BUCKET/models/v1/"
gcloud run services update credit-risk-api --project="$CREDIT_PROJECT" --region="$CREDIT_REGION" --update-env-vars="MODEL_BUCKET=gs://$CREDIT_BUCKET/models/v1"
curl --fail-with-body -sS --max-time 120 "$CREDIT_URL/model-info" | python3 -c 'import json,sys; x=json.load(sys.stdin); assert str(x["version"])=="1", x; print(json.dumps(x,indent=2))'
curl --fail-with-body -sS --max-time 120 "$CREDIT_URL/health"
)
```

Check that models/v1/ lists model.joblib, model_info.json and feature_store.parquet. Save the deployed revision and endpoint output. The folder must contain the Week 6 bundle with the production applicants, not an older 5,000-row export. Before rerunning this copy block later, confirm the root bundle is still the intended champion and that replacing models/v1/ is appropriate.

## Rollback practice and evidence

The course requires rollback practice even when the decision is keep. The teammate holding the MLflow registry runs python run.py rollback --version 1 as instructed by the course. If keeping version 1, the cloud exercise restarts that same champion.

After Step 6, run this separately in Cloud Shell. It obtains settings again so reconnecting does not leave empty variables.

```bash
(
set -e
CREDIT_PROJECT=credit-risk-group3-513720
CREDIT_REGION=us-central1
CREDIT_URL=$(gcloud run services describe credit-risk-api --project="$CREDIT_PROJECT" --region="$CREDIT_REGION" --format='value(status.url)')
test -n "$CREDIT_URL"
CREDIT_ROLLBACK_START=$(date +%s)
gcloud run services update credit-risk-api --project="$CREDIT_PROJECT" --region="$CREDIT_REGION" --update-env-vars=MODEL_BUCKET=gs://credit-risk-models-group3-513720/models/v1
curl --fail-with-body -sS --max-time 120 "$CREDIT_URL/model-info" | python3 -c 'import json,sys; x=json.load(sys.stdin); assert str(x["version"])=="1", x; print(json.dumps(x,indent=2))'
curl --fail-with-body -sS --max-time 120 "$CREDIT_URL/health"
CREDIT_ROLLBACK_END=$(date +%s)
printf '\nRollback update and verification: %s seconds\n' "$((CREDIT_ROLLBACK_END-CREDIT_ROLLBACK_START))"
gcloud run services describe credit-risk-api --project="$CREDIT_PROJECT" --region="$CREDIT_REGION" --format='yaml(status.latestReadyRevisionName,status.traffic,status.url,spec.template.spec.containers[0].env)'
)
```

The duration includes the update and verification calls. Save the actual measured value; do not substitute an estimate. If no challenger was deployed, describe this accurately as a same-version restart exercise, not a measured version-2-to-version-1 recovery. A rollback to version 1 leaves version 1 serving; any later restoration of a promoted version must follow the team's recorded decision.
